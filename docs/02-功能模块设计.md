## M1 状态管理

**职责**：定义诊断全生命周期的共享状态结构，贯穿 StateGraph 所有节点。

**文件**：
- `agent/state.py` — DiagnosisState TypedDict

**状态字段**：

| 类别 | 字段 | 类型 | 说明 |
|---|---|---|---|
| 输入 | `user_input` | `str` | 用户原始输入 |
| 输入 | `source_type` | `Literal[...]` | internal_robot / tb_task / remote_site / local_logs |
| 输入 | `extra_params` | `dict` | IP / TB链接 / 端口 / 日志路径 |
| 分析 | `materials` | `dict` | 采集产物 |
| 分析 | `findings` | `list[dict]` | 日志扫描发现 |
| 分析 | `error_codes` | `list[str]` | 提取的错误码 |
| 分析 | `problem_type` | `str` | navigation_rotate / safety / task_chain / ... |
| 分析 | `diagnosis_queue` | `list[dict]` | 错误码关联图排序后的排查队列 |
| 分析 | `deep_insights` | `list[dict]` | 6 项深层归因命中 |
| 分析 | `specialty_hits` | `list[str]` | 命中的专项 skill |
| Playbook | `playbook_matched` | `bool` | 是否命中 |
| Playbook | `playbook_error_code` | `str` | 命中的错误码 |
| Playbook | `playbook_root_cause` | `str` | 根因 |
| 证据 | `dingtalk_evidence` | `list[dict]` | 钉钉知识库检索 |
| 证据 | `gitlab_evidence` | `list[dict]` | GitLab 代码检索 |
| 证据 | `history_cases` | `list[dict]` | 历史 Case 匹配 |
| 多Agent | `doc_agent_result` | `dict` | 代码文档 Agent 结论 |
| 多Agent | `field_agent_result` | `dict` | 现场 Agent 结论 |
| 多Agent | `arbitration_result` | `dict` | 仲裁结论 |
| 融合 | `fusion_result` | `dict` | 融合或仲裁结果 |
| 结论 | `conclusion_status` | `Literal[...]` | confirmed / likely / need_human / insufficient_data |
| 控制 | `errors` | `list[str]` | 错误日志（累加） |
| 控制 | `fallback_triggered` | `list[str]` | 降级路径（累加） |

**依赖**：无

**状态**：🟡 已定义，开发中随节点实现可能增删字段
