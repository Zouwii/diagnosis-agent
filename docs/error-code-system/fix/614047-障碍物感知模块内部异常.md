## 触发条件（代码分析）

### safety_inspector_impl.cpp — CostmapResultId 映射
```cpp
impl_->result_map = {
  {CostmapResultId::InternalError,   AbnormalIds::PERCEPTION_INTERNAL_ERROR},
  {CostmapResultId::Collision,       AbnormalIds::PERCEPTION_COLLISION},
  {CostmapResultId::Timeout,         AbnormalIds::PERCEPTION_DATA_TIMEOUT},

```
导航控制器每个周期调用 costmap 检查，返回 `InternalError` 时触发。当 costmap 恢复正常后 `safety_inspector_impl.cpp:335` 恢复为 false。

## 常见原因
1. costmap 生成算法内部异常（内存不足、参数错误）
2. 传感器数据格式异常导致 costmap 解析失败
3. costmap 插件崩溃或未正常加载

## 排查思路

### Agent：日志排查
1. 查看 nav-controller 日志，关键字 `costmap`、`InternalError`、`PERCEPTION_INTERNAL_ERROR`

### Agent：Bag 排查（rostopic/rosservice 等只读操作）
1. `rostopic echo /scan` 检查激光数据是否持续更新
2. `rostopic echo /costmap` 检查 costmap 是否有正常数据输出

### 人员操作
（需要到现场/物理介入的事项）
1. 检查激光传感器外观是否有遮挡、脏污
2. 确认传感器供电和网线连接正常（指示灯闪烁）

### 需要人工审核的行为
1. 重启导航堆栈：`sudo systemctl restart nav-manager`
2. 更换传感器
