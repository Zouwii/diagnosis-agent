# 614002 地图异常

## jstate
`error/nav-manager/map_parse_error`

## 错误解释
导航加载或解析地图数据失败。

## 等级
level5（错误）

## 触发条件（代码分析）

### 触发点1：地图更新失败
**文件** `nav-manager/manager/src/plugin/nav_plugin.cpp:250-257`
```cpp
bool NavPlugin::onMapUpdate(...) {
  if (!map_handle_->onMapUpdate()) {
    monitor_hdl_->setStatus(AbnormalIds::MAP_PARSE_ERROR, true);
  }
```
`map_handle_->onMapUpdate()` 调用 `getNewMapInfo()` (map_manager.cpp:69)，获取 nodes/edges 失败时返回 false。成功后在 L271 恢复为 false。

### 触发点2：任务目标点解析失败
**文件** `nav-manager/navigation/nav_base/src/nav_base.cpp:284`
```cpp
if (parse_result.result == ParseResult::NODE_ATTRIBUTES_ERROR) {
  impl_->monitor->setStatus(AbnormalIds::MAP_PARSE_ERROR, true);
}
```
任务下发的目标 node_id 不在当前地图中。

## 常见原因
1. 地图文件损坏或版本不兼容
2. `/map_master/get_current_map_info` 服务异常
3. 任务下发目标 node_id 不在当前地图中
4. map-master / nav-manager 包版本不同步

## 排查思路

### Agent：日志排查
1. 查看 nav-manager 日志，关键字 `updateMap`、`getNewMapInfo`、`update map failed`

### Agent：Bag 排查（rostopic/rosservice 等只读操作）
1. `rosservice call /map_master/get_current_map_info "data: '[\"nodes\",\"edges\"]'"` 验证地图数据
2. 检查返回 JSON 是否包含 `nodes`、`edges` 字段且数据正常
3. 检查任务下发目标 `node_id` 在当前地图中是否存在
4. 检查 map-master / nav-manager 包版本一致性：`dpkg -l | grep nav-manager`

### 人员操作
（需要到现场/物理介入的事项）
1. 如刚更新过地图文件，确认地图源文件本身完整且版本正确
2. 如为硬件异常导致通信中断，检查工控机与传感器连接状态

### 需要人工审核的行为
1. 重启 nav-manager 服务
2. 重新下发地图文件
