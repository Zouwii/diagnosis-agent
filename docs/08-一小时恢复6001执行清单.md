## 固定 Prompt 要求

- 必须调用 `diagnosis-orchestrator` Skill。
- 必须读取指定 Case 的 `raw/` 材料。
- 必须将报告写到指定的 `report.md`。
- 只允许执行只读诊断操作。
- 遇到 403、空材料或关键材料缺失时，输出采集失败或材料不足，不得编造根因。
