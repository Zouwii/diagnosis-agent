## 1. 本地运行

### 1.1 环境准备

```bash
cd diagnosis-agent
cp .env.example .env
# 编辑 .env 填入真实 API Key

pip install -r requirements.txt
```

### 1.2 启动服务

```bash
# 启动 API 服务
python -m uvicorn server.main:app --port 6001 --reload

# 另开终端启动 Worker
python -m server.worker
```

API 在 http://localhost:6001/，Worker 不监听端口。

### 1.3 快速验证

```bash
# 创建 Case
curl -X POST http://localhost:6001/api/cases   -H "Content-Type: application/json"   -d '{"mode": "internal_robot", "robot_ip": "172.22.0.222",
       "symptom": "到点后旋转3圈停止"}'

# 查状态
curl http://localhost:6001/api/cases/{case_id}
```

## 4. 修改 LangGraph 图结构

当前图在 agent/graph.py 中定义，结构为：

```python
graph = StateGraph(DiagnosisState)
graph.add_node("run_cli_workflow", run_cli_workflow)
graph.add_edge(START, "run_cli_workflow")
graph.add_edge("run_cli_workflow", END)
```

添加新节点的步骤：
1. 在 agent/nodes/ 下创建节点实现
2. 在 agent/graph.py 中 add_node、调整边
3. 更新 agent/state.py 中相关字段
4. 更新 tests/test_graph_topology.py 中预期节点集合

## 8. 常见问题

**Q: Worker 不处理 Case？**
检查 DIAGNOSIS_STORAGE_ROOT 是否配置，Worker 轮询的目录是否正确。

**Q: SSE 流不推送？**
确认 Case 的 progress_events 字段在 case.json 中有更新。SSE 只读持久化文件，不依赖内存状态。

**Q: Playbook 加载失败？**
确认 source-docs/jstate_error_codes/agent/ 下存在对应错误码的 Agent 文档，且 YAML playbook 段格式正确。

**Q: LiteLLM 调用失败？**
检查 ai/config.json 或环境变量中的 API key 配置。模型路由会自动 fallback。

**Q: Nginx 代理 SSE 中断？**
确认 Nginx 配置了 proxy_buffering off 和 chunked_transfer_encoding on。
